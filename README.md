Sistema de Leilões

Descrição do Projeto

O Sistema de Leilões é um projeto desenvolvido em Java com o objetivo de informatizar as rotinas de uma casa de leilões.

O sistema permite o gerenciamento de produtos e operações relacionadas aos leilões, facilitando a organização e o controle das atividades.

Tecnologias Utilizadas

Java

MySQL

Git

GitHub

NetBeans IDE
